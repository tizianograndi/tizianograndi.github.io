# Sito personale — Prof. Tiziano Grandi

*(English version below)*

Sito statico composto da una landing page, pubblicato su **https://tizianograndi.github.io/**

## Struttura del progetto

```
.
├── index.html                       # Landing page
├── style.css                        # Foglio di stile
├── assets/
│   ├── favicon.svg                  # Favicon (iniziali TG)
│   ├── tiziano-foto.png             # Ritratto
│   └── tiziano-grandi-cv.pdf        # Curriculum Vitae
└── README.md
```

## Pubblicazione

Il sito è ospitato su **GitHub Pages**. Non richiede build step: è HTML e CSS puri.

1. Il repository deve chiamarsi esattamente `tizianograndi.github.io`.
2. In **Settings → Pages**, alla voce *Build and deployment*, scegliere *Deploy from a branch*, branch `main`, cartella `/ (root)`.
3. Attivare **Enforce HTTPS**.
4. Ogni commit sul branch `main` aggiorna il sito entro qualche minuto.

> **Importante:** l'URL è stampato su biglietto da visita e QR code. Non rinominare l'account GitHub né il repository, altrimenti l'indirizzo smette di funzionare.

## Publishing

The site is hosted on **GitHub Pages**. No build step required: it's plain HTML and CSS.

1. The repository must be named exactly `tizianograndi.github.io`.
2. In **Settings → Pages**, under *Build and deployment*, choose *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. Enable **Enforce HTTPS**.
4. Every commit to `main` updates the site within a few minutes.

> **Important:** the URL is printed on a business card and QR code. Do not rename the GitHub account or the repository, or the address will stop working.
